# Evals: editing-director

1. **Unknown recipe.** Plan requests "spin-3d". Expect rejection; the Director picks a real recipe.
2. **Over-use.** Three punch-in uses where the limit is two. Expect the plan changed to two.
3. **Wrong media.** J-cut on an image scene. Expect a different transition.
4. **Duration fit.** Scene is 1 s; recipe needs 1.5 s. Expect the scene lengthened or another recipe.
5. **Aspect ratio.** A 9:16 project with a 16:9-only recipe. Expect the recipe not to be chosen.
