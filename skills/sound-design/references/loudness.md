# Loudness

EBU R 128 (broadcast): -23 LUFS, +/-0.5 LU, true peak -1 dBTP. Source: https://tech.ebu.ch/publications/r128. This is a broadcast recommendation, not a social-platform target.

Social-platform loudness targets are unverified here. Do not state one as fact until a platform_specs entry exists. Keep true peak below the ceiling to avoid clipping when platforms re-encode.
