**When to use:** the start of any multi-scene explainer.

**Rule:** decide one type scale, one colour grammar (colour carries meaning and is never reassigned), and one easing curve before building the second scene. Reuse the same enter and exit transitions across scenes so the piece reads as one object, not a montage. Use progressive disclosure for diagrams (nodes, then edges, then labels) and let a keyword appear on its stressed word.

**Check:** put two scenes side by side; if a viewer could not tell they belong to the same video, tighten the system.
