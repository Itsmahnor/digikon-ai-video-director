**Visual-style skill adapted from the Lemo-Opuscar "dataviz" style. Draft: review before use.**

**When to use:** Use when real, sourced data is the story and the chart should drive framing and pace.

**Method:** Pick the chart the data asks for: bars for categories, lines for change over time, maps for place. Every mark is a real number and every motion is a meaningful chart operation: a mark lands, an axis grows, a scale changes, a note is pinned.

**Rule:** Colour encodes one thing, the value. Pale values stay pale; never stretch a scale to make a change look bigger. Keep ink colours for fixed meanings, such as human notes versus records.

**Caution:** Claims: use only data the user supplied or an openly licensed source that can be cited; never invent figures or sample values presented as real. Show the source on screen. The brand rules and the user's supplied assets still win, and a style is a guide, not a template. Do not imitate a living artist or another brand's identity.
