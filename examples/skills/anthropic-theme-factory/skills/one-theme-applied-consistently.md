**General visual-design skill (not video-specific).**

**When to use:** a deck, end card or set of slides needs consistent styling.

**Method:** a theme is a cohesive palette with hex values plus a header and body font pairing with a distinct identity. Show the options, get an explicit choice from the user, then apply that single theme to every element. Do not mix themes.

**Rule:** when the user supplies brand colours and fonts, those are the theme.
