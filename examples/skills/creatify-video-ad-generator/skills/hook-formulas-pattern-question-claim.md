**When to use:** every ad. The first three seconds decide whether the rest is seen.

**Structure:** pick one formula and state which one it is.
- *Pattern interrupt:* start mid-action (an unboxing, a dramatic reveal) or address the audience directly ("Stop scrolling if you run a small shop"). Best for broad, mobile audiences.
- *Question:* open a curiosity loop the viewer wants closed ("Why are accountants switching to X?"). Best for education and considered purchases.
- *Bold claim:* lead with the strongest benefit, stated plainly. Best when the benefit can be shown.

**Pacing:** spoken line, on-screen text and first visual all land inside 3 seconds; the product or result is visible by second 3.

**Claims warning:** a bold claim is only allowed when the claim is in the approved facts. "Saved 40%" needs a supplied source. Otherwise use a visible result, not a number.

**Example:** question hook, text "Still chasing invoices by hand?", first frame a cluttered inbox, second 3 the dashboard.
