**When to use:** a new feature ships and existing and prospective users should notice it.

**Structure:** the user's pain before, the feature in one action, the after-state, where to find it.

**Scene beats (20 s):** 0-3 s the old friction; 3-12 s the feature working (the money shot is before/after); 12-17 s one benefit line; 17-20 s "Available now" plus where to find it.

**Pacing:** the feature appears within 3 seconds; text readable on a phone; captions on.

**Asset needs:** real UI of the shipped feature, release name, availability (plans, regions), logo.

**Claims:** only claims backed by the facts the user supplied; no invented statistics, prices, customer names or testimonials; flag regulated claims (health, finance, legal) for review. Say "available now" only if it is. Do not state plan or pricing availability unless supplied.

**Example:** "Bulk reminders are here": before, sending reminders one by one; after, select all and send.
