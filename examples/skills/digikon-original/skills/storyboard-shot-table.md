**When to use:** before any build, and as the document the user approves at the first gate.

**Format:** one row per scene: number, start and end time, purpose in one line, visual (what is on screen and which supplied asset), on-screen text or caption, voice-over line, transition in, and the evidence behind any claim (the fact or asset it comes from). Add a totals row and a list of missing inputs.

**Rules:** every claim in a row cites a supplied fact; every visual names a supplied asset or says "needed"; the sum of durations matches the target; scenes that cannot be built with the available assets are marked, not hidden.

**Why:** the user approves what they can read in a minute; a table lets them correct a line before anything is built.

**Claims:** only claims backed by facts the user supplied; no invented statistics, prices, customer names or testimonials; flag regulated claims for review.

**Example row:** "3 | 8-14 s | show the reminder feature | recording clip 2, zoom on the Send button | 'Reminders send themselves' | VO line 4 | cut | fact: feature page 'Auto reminders'".
