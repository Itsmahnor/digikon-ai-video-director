**When to use:** a background or hero video on a website.

**Rules:** short seamless loop (about 6 to 15 seconds), silent by default, small file size, a poster frame for slow connections, no essential information only in the video, text contrast checked over the moving picture, and a pause control or reduced-motion respect.

**Pacing:** slow and calm; avoid fast flashes.

**Asset needs:** a clean visual of the product or brand, brand colours, the site's hero text layout.

**Claims:** only claims backed by the facts the user supplied; no invented statistics, prices, customer names or testimonials; flag regulated claims (health, finance, legal) for review.

**Example:** an 8 s loop of a dashboard being used, with the headline in static HTML text over it.

**Review checklist:** the loop point is invisible; the video is compressed for the web; the poster frame communicates the same message; the page text stays readable over every frame; the page still works if the video fails to load.

**Check first:** loop length, file size and autoplay rules change; confirm the current guidance for the site and browsers in use before delivery.
