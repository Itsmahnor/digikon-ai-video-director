**When to use:** any video with narration.

**Rules:** write for the ear: short sentences, contractions, one idea per line, concrete words, no jargon the viewer has not met. Open with the payoff or the problem, not the brand name. Say numbers the way they are spoken. Read the script aloud and time it before scene design; speaking pace is about 2.3 words per second for clear narration, slower for technical content. Leave a breath between ideas.

**Structure:** hook line, problem, solution, how in up to three steps, payoff, CTA with the place to go.

**Check:** if a line needs two breaths, split it; if a line repeats the on-screen text word for word, change one of them.

**Claims:** only claims backed by facts the user supplied; no invented statistics, prices, customer names or testimonials; flag regulated claims for review.

**Example:** "Chasing late invoices? There is a quieter way. Set the reminder once, and it sends itself."
