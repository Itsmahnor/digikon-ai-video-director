**When to use:** the scene needs a named effect or component (a chart, glitch, film grain, kinetic type, a caption style, a map overlay, a 3D piece).

**Rule:** search the block registry first and install it as editable source, then adapt. Hand-build only when nothing fits. Re-using a verified block is faster and less likely to break the render contract.

**Caution:** adapted blocks still have to pass the same checks and frame inspection as hand-built ones.
