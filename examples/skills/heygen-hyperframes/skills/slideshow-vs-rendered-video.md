**When to use:** the user says "deck" or "presentation" but the output is shown live.

**Rule:** if the content will be presented live with speaker notes, fragment reveals or branching, build a slideshow, not a rendered MP4. If it will be shared as a file or a social clip, render a video. Decide this before storyboarding.

**Claims:** the same claim rules apply to slides as to video; every statement needs a supplied source.
