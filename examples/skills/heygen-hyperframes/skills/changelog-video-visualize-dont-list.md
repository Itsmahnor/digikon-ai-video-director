**When to use:** weekly or release changelog videos for existing customers.

**Rule:** visualize, do not list. Illustrate each theme with an animated mock of the real UI (or a faithful analogue) acting out the change; use a text checklist only for genuinely non-visual items such as reliability fixes. Decide the visual treatment for every item before writing the script.

**Structure:** square format, about 45 to 60 seconds, voice-over, quiet captions, one consistent brand background.

**Claims warning:** show only changes that really shipped; do not dramatise or invent UI.

**Example:** "Bulk reminders" is shown as the real bulk-select flow, not as a bullet.
