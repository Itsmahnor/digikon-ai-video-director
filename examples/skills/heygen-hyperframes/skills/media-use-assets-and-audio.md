**When to use:** a scene needs media the user has not supplied.

**Rule:** media lands as a local file in the project with a ledger record of where it came from; renders never fetch at render time. Prefer free catalogues and local tools, credit-required licences (such as CC BY) must carry their credit, logos are taken from the brand's own sources and never redrawn, and voice-over, music and sound effects are added only where the request or story calls for them.

**Ask first:** if the logo, footage or licence status is unknown, ask the user instead of substituting.
