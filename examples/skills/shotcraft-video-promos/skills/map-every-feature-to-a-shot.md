**When to use:** at storyboard time for any feature-led promo.

**Rule:** list the product's features first and map each core feature to a shot. A core feature missing from the film means rework. Rank features by what the viewer needs to believe, and cut the rest.

**Example:** invoicing app: create invoice, auto-reminder, payment received, report. Four shots, each with its on-screen proof, and a fifth for the closing mark.

**Claims warning:** only features that exist in the product, and only as shown in real captures.

**Check:** tick the feature list against the storyboard; every core feature should appear in a shot, and every shot should serve a feature or the closing mark.
