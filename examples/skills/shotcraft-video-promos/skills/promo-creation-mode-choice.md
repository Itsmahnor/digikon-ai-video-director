**When to use:** the user asks for a full product promo without saying how involved they want to be.

**Modes:** (1) use a proven template and swap in the product's captures, copy and brand; (2) autonomous creation, where the agent decides direction, shot mapping, storyboard, assets and audio and carries on to a finished film; (3) guided creation, where the user confirms the product brief, decisions, visual direction, shot mapping and final storyboard before final assets are captured.

**Method:** do a minimal read-only check of the product first, then recommend a mode with reasons and ask the user to choose; never start production before they do. If the user names a template or specific shots, treat that as their choice.

**Caution:** do not modify the user's project, collect sensitive data or write video code during the check.
